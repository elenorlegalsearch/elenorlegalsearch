| Datei | Zweck |
| --- | --- |

| `bewerber.html` | Bereich für Bewerber:innen (Profil per E-Mail) |
| `vakanzen.html` | Offene Vakanzen |
| `ueber-mich.html` | Über mich |
| `impressum.html`, `datenschutz.html`, `agb.html` | Rechtstexte |
| `404.html` | Fehlerseite |
| `assets/` | Design (`site.css`, `els.css`), Schriften, Foto, Skripte (`i18n.js` = DE/EN, `els.js`, `analytics.js`) |
